Add `@endo/daemon/grants.js` for retained, fail-closed filesystem and Git
provisioning without a coding harness.
The API normalizes inert policy, introduces attenuated mounts, Git capabilities,
remotes, and named host powers into a retained guest, and returns a versioned
non-secret reconstruction record.

Keep `@endo/agentry/code-mode-provisioning` as a compatibility adapter over the
daemon lifecycle.
Code-mode persistence advances to version 3 so prompt context remains outside
the daemon authority record; version 2 sessions must be reprovisioned.
